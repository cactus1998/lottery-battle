# PRD：毒圈（zone）— 已移除

> 2026-10-06 依使用者要求移除縮圈，改用延長賽保證結束，見 [PRD-overtime.md](PRD-overtime.md)。以下為原規格紀錄。

## 目標

保證每場在時限內結束，並讓後期小人往中央集中，製造決戰感。

## 範圍

- **Must**：15 秒開始縮，50 秒縮到半徑 0；圈外每秒扣 8 HP；圈外的小人優先往中心移動；`zone-start` 事件。
- **Won't**：隨機圈心（之後可加，會改變 golden test）。

## 邊界情況

| 編號  | 情境                    | 預期行為                                            |
| ----- | ----------------------- | --------------------------------------------------- |
| EC-01 | 多人同時在圈外、HP 相同 | 依 rng 洗牌順序逐一扣血，達到得獎人數時立即停止結算 |
| EC-02 | 半徑縮到 0              | 所有人都在圈外，最慢約 50 + 150 / 8 ≈ 69 秒結束     |

## 驗收標準

- [x] AC-01：所有測試人數在 90 秒內結束（`world.test.ts` 斷言 `durationSec ≤ 90`）。
- [x] AC-02：15 秒前 `zone.active` 為 false。

## 開發紀錄

- 圈外扣血與戰鬥共用「逐一結算、死亡立即檢查勝負」的規則（`systems/death.ts` 的 `killUnit` 回傳是否結束）。
- 畫面用 evenodd 填色畫圈外區域，毒圈開始時顯示 2.5 秒橫幅。
