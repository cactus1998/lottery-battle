# PRD：延長賽（overtime）

## 目標

取代毒圈：不縮圈，但保證對戰一定會結束。

## 範圍

- **Must**：90 秒後全員傷害 ×2，之後每 30 秒倍率 +1；進入或升級時發出 `overtime` 事件，畫面顯示橫幅與 HUD 提示；300 秒安全上限依 HP 強制結算。
- **Won't**：縮圈、地形傷害。

## 驗收標準

- [x] AC-01：`damageMultiplierAt` 在 89 秒為 1、90 秒為 2、120 秒為 3（`world.test.ts`）。
- [x] AC-02：所有測試人數在 `maxTicks` 前結束。

## 開發紀錄

- 依目前數值，實測數百場都在 90 秒內自然結束，延長賽只是保險。
