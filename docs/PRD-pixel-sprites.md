# PRD：像素小人偶（pixel-sprites）

## 目標

把圓點換成看得出職業的像素小人偶。

## 範圍

- **Must**：16×16 像素 sprite 以字元圖層定義（腳、身體、頭、帽子、武器）；衣服顏色依每人色相；動作幀 站立 / 走路 A / 走路 B / 攻擊；面左右與受擊白共 4 列；像素草地、墓碑、陰影；依 y 排序繪製；投射物（箭、火球）與爆炸、旋風斬光圈；設定頁職業介紹預覽、HUD 與結果頁職業圖示。
- **Won't**：外部素材包（之後若要換成 CC0 素材，下載前先詢問使用者）。

## 資料與介面

- `src/render/sprites.ts`：`buildUnitAtlas(classId, hue)` 產生 64×64 atlas（ImageData 一次寫入）、`buildGrass`、`buildPixelCanvas`。
- `src/components/ClassIcon.tsx`、`ClassPortrait.tsx`；`src/features/setup/ClassGuide.tsx`。

## 驗收標準

- [x] AC-01：每個職業每個動作幀的圖層都是 16×16，攻擊幀與站立幀不同（`sprites.test.ts`）。
- [x] AC-02：Chrome 實測 300 人 60 FPS，小人偶身體不互相重疊（依 y 排序繪製，頭部可被前排遮住）。
- [x] AC-03：小人站在場地邊緣時，名字不超出畫面。

## 開發紀錄

- 不使用外部素材，避免授權與下載問題；像素圖直接寫在程式裡，方便日後調整。
- 場地四周保留空間（上 50、左右與下 30 單位），名字會限制在畫面內，站在邊緣的小人頭部與名字不會被切掉。
- 依使用者要求加大碰撞體積：碰撞半徑 8 → 14，小人偶像素大小固定為 3.5 單位（身體寬 28 = 兩倍碰撞半徑），畫面上不再互相重疊；近戰射程 18 → 34、旋風斬 32 → 46、火球爆炸 40 → 50、遠程後退距離同步放大。30 人勝率與時長和調整前相近（平均 60 秒）。
