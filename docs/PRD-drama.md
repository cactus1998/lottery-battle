# PRD：結尾戲劇效果（drama）

## 目標

比賽接近結尾時用鏡頭、速度與特效拉高緊張感，讓公布得獎者的那一刻更有記憶點。全部是畫面效果，不影響模擬結果（同 seed 結果不變）。

## 範圍

- **Must**
  - 決戰時刻（存活 ≤ 得獎人數 + 2，且至少已淘汰一人）：鏡頭平滑拉近框住存活者（最大 2.4 倍）、遊戲速度 ×0.7、四周暗角、鼓聲、橫幅「⚔️ 決戰時刻！」、HUD 提示。
  - 賽點（只差一人分出勝負，且有人血量 < 35%）：速度 ×0.4、暗角加深、HUD「🔥 賽點！」。
  - 最後一擊：停格 0.25 秒 → 慢動作 1.5 秒（特效 ×0.3）；白光閃爍、強震、雙層衝擊波、大量粒子；鏡頭衝向出手者與倒下者之間（2.8 倍）；大字「最後一擊！」與「A 擊倒 B」。結果頁延後到 3.5 秒後出現。
  - 鏡頭不拍到場地外。
  - `prefers-reduced-motion`：不拉鏡頭、不閃光、不震動、不停格，只保留放慢。
- **Won't**：預先模擬找出最後一擊再倒轉播放（需要複製 rng 狀態）。

## 資料與介面

- `src/game/drama.ts`：`dramaLevel(world)` 回傳 `none` / `final` / `matchPoint` / `finished`；`DRAMA_TIME_SCALE`。
- `src/render/camera.ts`：`Camera`（`follow`、`punch`、`update` 指數平滑）、`frameAlive`、`clampTarget`。
- `Effects` 新增 `flash`、`vignette`、`finalTitle` / `finalSubtitle`；`Renderer.draw` 新增 `camera` 參數與 `drawOverlays`。
- `HudSnapshot.drama`。

## 邊界情況

| 編號  | 情境                         | 預期行為                          |
| ----- | ---------------------------- | --------------------------------- |
| EC-01 | 3 人取 1 名，一開場就 ≤ 3 人 | 第一個人倒下前不進入決戰          |
| EC-02 | 最後一擊來自法師火球範圍傷害 | 鏡頭對準倒下者與鎖定他的存活者    |
| EC-03 | 按「直接看結果」             | 跳過所有戲劇效果直接到結果頁      |
| EC-04 | 存活者站在場地邊緣           | 鏡頭中心被限制，畫面不超出場地    |
| EC-05 | 使用者選 4x                  | 戲劇倍率乘在 4x 上（決戰約 2.8x） |

## 開發紀錄

- 因為引擎是固定步長，放慢只要把每幀加進 accumulator 的時間乘上倍率，模擬結果完全不受影響。
- 倍率用指數平滑變化，避免從 1 倍突然掉到 0.4 倍。
