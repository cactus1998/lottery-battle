# PRD：職業（classes）

## 目標

讓每場對戰更有變化：參加者開打時隨機成為劍士、騎士、弓箭手、法師或刺客，各有不同的打法。

## 範圍

- **Must**：五種職業數值（`src/engine/classes.ts`）；用 seed 洗牌發牌，各職業人數最多差 1；遠程職業發射箭矢 / 火球投射物；劍士旋風斬；法師火球爆炸範圍傷害；騎士護甲；刺客優先鎖定 220 內的遠程職業；遠程被貼近時後退（速度七折，近戰追得上）。
- **Won't**：使用者指定職業、裝備或升級。

## 資料與介面

- `ClassStats`：`maxHp`、`speed`、`range`、`retreatRange`、`damageMin/Max`、`cooldown`、`critChance`、`critMultiplier`、`armor`、`projectileSpeed`、`splashRadius`、`splashRatio`、`spinEvery`、`spinRadius`、`spinRatio`、`huntRadius`。
- `Unit` 新增 `classId`、`maxHp`、`attackCount`；`World` 新增 `projectiles`（物件池）。
- 事件新增 `shoot`、`explode`、`spin`。
- `RankingRow` 新增 `classId`。

## 邊界情況

| 編號  | 情境                       | 預期行為                                   |
| ----- | -------------------------- | ------------------------------------------ |
| EC-01 | 少於 5 人                  | 從洗牌後的職業清單取不重複的幾種           |
| EC-02 | 投射物飛行中目標死亡       | 箭矢消失；火球飛到最後位置照樣爆炸         |
| EC-03 | 投射物飛行中主人死亡       | 照樣命中，擊殺算在主人身上                 |
| EC-04 | 範圍傷害波及多人並達到勝負 | 依索引順序逐一結算，剩下得獎人數時立即停止 |

## 驗收標準

- [x] AC-01：23 人時五種職業都有，人數最多差 1（`world.test.ts`）。
- [x] AC-02：同 seed 職業分配相同，結果可重播。
- [x] AC-03：各人數下結束時存活數剛好等於得獎人數。

## 開發紀錄

- 第一版沒有獵殺機制，300 人時弓箭手勝率 88%（遠程站後排撿尾刀）。加入刺客優先刺殺遠程、削弱弓箭手後，騎士變成 92%；再把騎士護甲 30% 降到 25%、HP 調整後，30 人時各職業勝率 9%–29%。
- HP 第一次提高到 250–480 時 30 人平均 50 秒，使用者希望更久，再提高約 1.4 倍到 500–780，30 人平均 60 秒、300 人 69 秒。
- 刺客勝率仍偏低（約 8%），但平均名次中上；之後若要再調整，以 `game-engine` skill 的平衡流程進行。
