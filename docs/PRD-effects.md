# PRD：打擊特效（effects）

## 目標

讓打鬥有打擊感，同時不影響結果的公平性。

## 範圍

- **Must**：受擊閃白 3 tick、攻擊時武器伸出、傷害數字（存活超過 60 人時只顯示爆擊）、死亡粒子 14 顆、爆擊與擊殺時鏡頭震動、勝利者金框與煙火；`prefers-reduced-motion` 時關閉震動並減少粒子。

## 驗收標準

- [x] AC-01：特效只在 `render/effects.ts`，使用 `Math.random` 不影響引擎（golden test 不變）。
- [x] AC-02：粒子上限 600、傷害數字上限 60。

## 開發紀錄

- 特效用真實時間更新，暫停時一起停止。
