# PRD：結果畫面（result-screen）

## 目標

公布得獎者，提供完整名次，並能重播或再來一場。

## 範圍

- **Must**：頒獎台（前三名站在高・中・低台子上，畫面順序 2・1・3，台上是該名參加者的像素小人偶；第 1 名戴皇冠、擺攻擊姿勢；前三名中未得獎者標示「未得獎」）、得獎人數超過 3 時的「其他得獎者」列表、擊殺王與第一個出局、完整名次表（50 人以下預設展開）、重播這場、同名單再來一場、複製結果、重新設定、顯示 seed。
- **Won't**：匯出圖片。

## 邊界情況

| 編號  | 情境                     | 預期行為                     |
| ----- | ------------------------ | ---------------------------- |
| EC-01 | 剪貼簿權限被拒           | 顯示「複製失敗，請手動選取」 |
| EC-02 | 沒有任何擊殺（全被毒死） | 不顯示擊殺王                 |

## 驗收標準

- [x] AC-01：顯示每位得獎者與 n + 1 列表格（`ResultScreen.test.tsx`）。
- [x] AC-02：重播使用同一個 seed，且不新增歷史紀錄。
- [x] AC-03：複製的文字等於 `formatResultText(result)`。
- [x] AC-04：頒獎台 DOM 依名次 1・2・3 排列（螢幕閱讀器順序正確），畫面以 CSS `order` 排成 2・1・3（`Podium.test.tsx`）。
- [x] AC-05：取 5 名時，第 4、5 名列在「其他得獎者」。

## 開發紀錄

- 存活者之間的名次依剩餘 HP、擊殺數、名單順序排序；淘汰者依死亡先後倒序。
- 只在宣布得獎者時用 `aria-live`，戰鬥中的戰報不用 live region。
- 2026-10-06 依使用者要求把頒獎卡片改成頒獎台；`RankingRow` 新增 `hue`，讓結果頁畫出和對戰中同樣顏色的小人偶。
