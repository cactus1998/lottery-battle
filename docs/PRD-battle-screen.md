# PRD：對戰畫面（battle-screen）

## 目標

觀看混戰，可控制速度與暫停，看到即時戰況。

## 範圍

- **Must**：Canvas 競技場、HUD（存活、時間、取幾名、擊殺王、5 筆戰報、毒圈 / 勝負提示）、控制列（暫停、1x / 2x / 4x、直接看結果、音效、FPS、放棄）、鍵盤快捷鍵（Space、1 / 2 / 4、S、M、F）。
- **Won't**：點選小人看詳細資料。

## 邊界情況

| 編號  | 情境                 | 預期行為                                   |
| ----- | -------------------- | ------------------------------------------ |
| EC-01 | 焦點在按鈕上按空白鍵 | 交給瀏覽器觸發按鈕，不重複切換暫停         |
| EC-02 | 焦點在輸入框         | 快捷鍵不作用                               |
| EC-03 | 重播同一場           | 換 `key` 重新掛載，建立新的 GameController |

## 驗收標準

- [x] AC-01：按 Space 暫停 / 繼續；按 4 切到 4 倍速並記住偏好（`App.test.tsx`）。
- [x] AC-02：直接看結果後進入結果頁。
- [x] AC-03：375px 寬時場地、控制列、HUD 由上到下排列。

## 開發紀錄

- HUD 由 `useGameSnapshot` 驅動；對戰中只有 HUD re-render，Arena 元件不會因每幀更新而 re-render。
- 速度、音效、FPS 偏好在事件處理中同時呼叫 controller 並寫入 store，不用 effect 同步。
